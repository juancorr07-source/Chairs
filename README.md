# sillas
Present design alternatives, using inheritance and polymorphism, for managing a list of chairs in a factory's inventory.

## Chair Categories
The program supports the following chair categories:

- **Presidential:** includes information about its origin (domestic or imported).
- **Executive:** executive office chair.
- **Secretarial:** chair designed for secretarial use.
- **Wheelchair:** includes the traction type (manual or automatic).
- **Tandem:** includes the number of seats.
- **Massager:** includes usage modes and heating functionality.

## Input File
Inventory information is loaded from a CSV file, where each line represents a chair.

Fields are separated by commas and vary depending on the chair category.

## Technologies
- Java 17 or higher.
- Object-oriented programming (OOP).
- Java Collections (`List` and `ArrayList`).
- File reading using `Scanner`.

## Execution
Run the `Main` class from your development environment to start the program, and writing the txt file that will be used.
